This is a career-integration week (week 2 at the new firm — first *bigger* task assigned and submitted), not a Build week. There is no crate, no upstream mirror, and no engineered trap-test arc — manufacturing one would be padding. Every item instead names its artifact file + an Output line that proves it done, and the substantive learning/judgment items carry a 🎯 hardened-acceptance pass criterion + a *mental model* of why the item exists now.
