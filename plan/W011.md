  - **The problem this primitive solves**: every other queue in the workspace eventually wants "bounded,

  #### Phase 3 — Make the tests pass, one failure at a time (~120 min)

  - **When `mpmc_loom_2p_2c_cap2_wraparound` reports "slot N holds two values" within seconds:**
    - Symptom: loom finds a schedule where two producers wrote to the same slot.
    - Why: capacity not power-of-2 OR you used `%` instead of mask; aliasing introduced.
    - Fix: assert `cap.is_power_of_two()` in `new()`; use `idx & (cap - 1)` mask everywhere.
    - Muscle: power-of-2 + mask is the safe index; modulo allows aliasing under non-pow2. Reapplies at:
      W26 SegQueue, W77 aeron term buffer.

  - **When `mpmc_loom_2p_2c_cap2_wraparound` reports "consumer observed uninit slot data" on aarch:**
    - Symptom: consumer sees seq bumped but slot still has old/garbage data.
    - Why: seq store with Relaxed; aarch64 reorders the seq store before the data write.
    - Fix: producer's seq-release uses `Release`; consumer's seq-load uses `Acquire`. Pair carries the
      data write.
    - Muscle: per-slot seq is a lock — Release on producer-bump pairs with Acquire on consumer-check.
      Reapplies at: W26 SegQueue, W65 Disruptor, W77 aeron.

  - **When `mpmc_head_tail_separate_cache_lines` reports offset_of delta = 8 (same line):**
    - Symptom: head + tail on same 64B line. Producer touches tail, consumer touches head, false-share.
    - Why: declared `struct { head: AtomicUsize, tail: AtomicUsize }` without CachePadded or repr(C)
      reordered fields.
    - Fix: `#[repr(C)] struct BoundedRing { head: CachePadded<_>, tail: CachePadded<_>, buf: … }`.
      `offset_of!` static assert delta >= 128.
    - Muscle: producer + consumer cursors on a lock-free queue MUST be in separate cache lines.
      Reapplies at: W26 SegQueue head/tail, W65 Disruptor claim/cursor, W74 raft term+index, W77 aeron
      term rotation counter pair.

  - **When `mpmc_recv_on_empty_blocks_via_parker` shows 100% CPU:**
    - Symptom: consumer burns a core.
    - Why: bare while-loop without Backoff or Parker.
    - Fix: Backoff ladder; after N spins, Parker::park. Sender calls `unpark` after success.
    - Muscle: every blocking primitive eventually parks; Backoff is the ladder. Reapplies at: W26 WAL
      group-commit ack, W42 LockManager waiter wake.

  - **When `mpmc_scale_curve_16x_at_n16` shows <5× at N=16:**
    - Symptom: sublinear scaling; sub-cliff.
    - Why: either head/tail on same line (CachePadded missing), or producers contend on a single CAS
      that should be per-slot.
    - Fix: re-verify CachePadded + per-slot seq; profile under criterion's multi-thread harness; if
      still sub-cliff, head-counter contention dominates and you need producer-sharded heads (W14
      drill).
    - Muscle: scaling cliffs ALWAYS point at a single hot cache line. Reapplies at: W42 next_id, W74
      raft batching.

    practical, the per-slot-seq lock-free design loses to lock-free + wait-free hybrids. Migration:
    abstract the Channel trait; LCRQ as a behind-feature impl. Trigger: ≥256 producers in a real
    workload.
