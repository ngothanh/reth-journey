  - 🎯 **Pre-prediction prompt** — write sealed answers in `crates/exec-vm/notes/09_stack_prediction.md`:

  - *Mental model*: a fixed-depth (1024) LIFO of 256-bit words; the operand workspace every opcode reads/writes.
  - *Contract*: `Stack(Vec<U256>)` with `new() -> Self`, `push(&mut self, v: U256) -> Result<(), InstructionResult>`, `pop(&mut self) -> Result<U256, _>`, `dup(&mut self, n: usize) -> Result<(), _>`, `swap(&mut self, n: usize) -> Result<(), _>`, `ensure_n(&self, n: usize) -> Result<(), _>`. NEVER the body.
  - *Back-of-envelope*: push/pop must be **~1-2 ns** (a bounds branch + an L1 store of 32 bytes). The EVM runs millions of ops per block; at ~1 ns/op the stack is invisible, but a SINGLE mid-execution `Vec` realloc = **~50 ns malloc + memcpy of the live region** — 25-50× the op cost, and it strikes unpredictably when `len` crosses a power-of-two. Hence: pre-size to 1024 ONCE so the capacity branch in `push` never reallocs (cold 50 ns realloc vs warm ~1 ns push = **~50× cliff**). Returning `U256` by value copies **32 bytes = half a cache line** per pop; on the hottest structure in the EVM that copy is measurable across a block.

    - R1. `Stack` wraps a `Vec<U256>` pre-sized to 1024 capacity (`Vec::with_capacity(1024)`), NEVER `Vec::new()`.
    - R2. `push` returns `Err(StackOverflow)` when `len() == 1024`. NEVER grows past — the 1024 check guards BOTH consensus AND the no-realloc invariant.
    - R3. `pop` returns `Err(StackUnderflow)` on empty. NEVER panics.
    - R4. `dup(n)` (1-indexed from top): reads index `len - n`, pushes. Requires `len >= n` AND `len < 1024`.
    - R5. `swap(n)` (1-indexed): exchanges `len-1` with `len-1-n`. Requires `len > n`.
    - R6. Every opcode pre-checks min stack height (ADD = 2, ADDMOD = 3) via `Stack::ensure_n(n)`.

  - *Mental model*: a fetch-decode-execute loop over a byte slice; `step` fetches one opcode, dispatches to its handler, the handler mutates stack/memory/gas/pc, `run` loops until `instruction_result` is set.
  - *Contract*: `Interpreter { pc, bytecode: Bytes, stack: Stack, memory: SharedMemory, gas: Gas, instruction_result: InstructionResult }`; `step(&mut self, host: &mut dyn Host)`, `run(&mut self, host) -> InstructionResult`; dispatch table `static TABLE: [fn(&mut Interpreter, &mut dyn Host); 256]`, read at the dispatch site as `let f = TABLE[op as usize]; f(self, host)` (NOT a `match`).
  - *Back-of-envelope*: at one dispatch per opcode and millions of opcodes per block, the dispatch shape is load-bearing. A `[fn;256]` **indirect call is ~2-5 ns** (one load of the slot + an indirect branch the BTB predicts well once warm); a 256-arm `match` the compiler may lower to a **jump table (also ~2-5 ns) OR — if arms aren't dense/contiguous — to a comparison chain that is O(opcode value) branches**, each a potential ~5 ns mispredict. The function-pointer table also keeps the dispatch site to **one cache line** of code regardless of opcode count, whereas a giant `match` body bloats the icache footprint of the hot loop. Choose `[fn;256]` so dispatch cost is constant and predictable.

    - R3. `step` advances `pc` by 1 BEFORE the handler runs. Handlers may overwrite `pc` (JUMP/JUMPI).
    - R4. PUSHn handler consumes `n` immediate bytes from `bytecode[pc..pc+n]` and advances `pc += n`.
    - R5. `pc >= bytecode.len()` is implicit STOP, not panic.
    - R6. Run loops `step` until `instruction_result` is set.

This is the negative-control: it proves the table is on the live dispatch path, not a passive constant.

  use std::sync::atomic::{AtomicUsize, Ordering};
  static PROBE_HITS: AtomicUsize = AtomicUsize::new(0);
  fn probe_handler(_i: &mut Interpreter, _h: &mut dyn Host) { PROBE_HITS.fetch_add(1, Ordering::Relaxed); }

  #[test]
  fn interpreter_step_dispatches_through_table_slot() {
      // Test-only hook: swap the handler for opcode 0x01 (ADD) in the dispatch table.
      // Requires `step` to do `let f = TABLE[op as usize]; f(self, host)` — a match-chain cannot pass.
      let saved = install_handler(0x01, probe_handler); // returns the previous fn for restore
      PROBE_HITS.store(0, Ordering::Relaxed);
      let mut interp = Interpreter::new(Bytes::from_static(&[0x01])); // single ADD opcode
      let mut host = NoopHost::default();
