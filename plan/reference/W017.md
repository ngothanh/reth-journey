  #### Phase 3 — Make the tests pass, one failure at a time (~90 min)

  - **(NEWBIE) When `env_eip1559_underflow_returns_err` panics:**
    - Symptom: `basefee > max_fee` triggers `basefee + max_priority - max_fee`-style arithmetic underflow

    - Why: didn't validate the precondition before computing `effective_gas_price`.
