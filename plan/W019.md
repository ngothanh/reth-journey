- [ ] **Build**: `crates/exec-vm/src/precompile/mod.rs` — Precompile trait, PrecompileRegistry. Implement ECRECOVER
  first. (~75 min)
  - **Why**: Precompiles are gas-priced "syscalls" — fixed addresses (0x01..0x0a, plus Cancun additions) that execute native code instead of bytecode. ECRECOVER (0x01) is the single most-called precompile (every EOA tx verification path). It must produce the *exact same* recovered address as every other client or your node forks.
  - **Read first**: revm `crates/precompile/src/secp256k1.rs` (the ec_recover impl, ~80 lines) and `crates/precompile/src/lib.rs` (the `Precompile` and `PrecompileSet` types). Also EIP-2 for ECDSA y-parity normalization rule.
  - **Design**:
    ```rust
    pub trait Precompile: Send + Sync {
        fn run(&self, input: &[u8], gas_limit: u64) -> Result<PrecompileOutput, PrecompileError>;
    }
    pub struct PrecompileOutput { pub gas_used: u64, pub bytes: Bytes }
    pub struct PrecompileRegistry {
        entries: BTreeMap<Address, Arc<dyn Precompile>>,  // Spec-gated
    }
    pub fn ec_recover(input: &[u8], gas_limit: u64) -> Result<PrecompileOutput, PrecompileError> {
        const ECRECOVER_GAS: u64 = 3000;
        if gas_limit < ECRECOVER_GAS { return Err(PrecompileError::OutOfGas); }
        let mut padded = [0u8; 128];
        padded[..input.len().min(128)].copy_from_slice(&input[..input.len().min(128)]);
        let msg = &padded[0..32];
        let v = U256::from_be_slice(&padded[32..64]);
        let r = &padded[64..96];
        let s = &padded[96..128];
        // 1. v must be 27 or 28; reject others (NOT EIP-155 chain-id-folded v here).
        // 2. s must be in lower half [1, n/2] (EIP-2).
        // 3. secp256k1::recover; on failure return empty bytes (NOT error).
    }
    ```
    **Invariants**:
    - Input zero-padded to 128 bytes if shorter; truncated if longer.
    - On *signature failure* (bad r/s, bad v, recovery returns no pubkey) → return *empty bytes* with full gas charged (not error!).
    - Output, when valid, is 32 bytes: 12 zero bytes + 20-byte address.
    - s in lower half: `s <= n/2` where n is secp256k1 order (EIP-2). Pre-Homestead allowed both halves; revm gates this on spec.
  - **Build steps**:
    1. (~15 min) Wire `k256` or `secp256k1` crate (decide: revm uses `secp256k1` with `recovery` feature for speed).
    2. (~15 min) Input padding helper; unit-test edge cases (0-byte, 1-byte, 129-byte inputs).
    3. (~15 min) Implementation matching above; failure = `Ok(empty)`, not `Err`.
    4. (~10 min) `Precompile` trait + `PrecompileRegistry::new_with_spec(SpecId)` that mounts ECRECOVER at 0x01.
    5. (~10 min) Hook into your dispatcher: CALL/STATICCALL with `to` in `[0x01..0x0a]` short-circuits into registry.
    6. (~10 min) Tests: known mainnet ECRECOVER calls round-trip.
  - **Pitfalls**:
    - *Returning Err on bad signature*: this is THE classic precompile bug. Specs say "valid signature → address, invalid → empty bytes, no error". **Symptom**: any tx that calls ECRECOVER with a deliberately bad sig (common for delegate-paths) reverts incorrectly. **Fix**: only `PrecompileError::OutOfGas` is a real error; everything else is `Ok(PrecompileOutput { gas_used: 3000, bytes: Bytes::new() })`.
    - *v normalization*: input `v` is one of {27, 28}; the SDK's recover_id wants 0/1. **Symptom**: address recovered correctly half the time. **Fix**: `recovery_id = (v - 27) as u8`; bail on anything else.
    - *Malleable s-values*: pre-Homestead allowed `s > n/2`. Post-Homestead must reject. **Symptom**: replay diverges on pre-Homestead history. **Fix**: gate the high-s rejection on `spec_id >= HOMESTEAD`.
    - *Crate selection — k256 vs secp256k1*: k256 is pure-Rust (auditable); secp256k1 wraps libsecp256k1 (~3-5× faster). **Symptom**: bench shows ECRECOVER as dominant in tx-validation hot loop. **Fix**: feature-flag both; default to secp256k1 for production paths.
  - **Test scenarios**:
    - Official EIP-155 test vector: known (v, r, s, msg) → known address.
    - All-zero input: returns empty bytes, charges 3000 gas.
    - 1-byte input zero-padded: still returns empty bytes (msg=0, sig=invalid).
    - High-s pre/post-Homestead: pre accepts, post returns empty.
    - Gas exactly 3000: succeeds. 2999: OutOfGas error.
  - **Acceptance**:
    - Pass `stPrecompiledContracts/CALL_BoundsOOG`, `stPrecompiledContracts2/ECRecoverRecoveredKey`.
    - Inheritance ratio 1.0 vs revm `secp256k1.rs` (only difference: import path).
    - Bench: ≥ 50k ECRECOVER calls/sec single-thread (revm baseline).
  - **Downstream**: W19 modexp/pairing reuse `Precompile` trait shape; W74 matching-engine signature verification reuses same secp256k1 path; W83 ledger uses ECRECOVER for tx-signing checks.
