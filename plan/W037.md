  - *Mental model*: EBR replaces per-object refcounts with a global epoch clock. A writer retires an object into the
    current epoch's bag; the object is freed only once the epoch advances twice (all readers that could have observed
    it have unpinned). `try_advance` is the clock tick — it must prove global quiescence before it ticks.
  - *Contract*:
    `fn try_advance(&self, local: &Local) -> bool` — returns true iff the global epoch advanced; on advance, drains
    the bag two epochs back. `fn defer(&self, garbage: Garbage, local: &Local)` — pushes into the current-epoch bag.
    Epoch is `AtomicUsize` wrapped in `CachePadded` (read on every pin, written rarely → false-sharing target).
  - *Back-of-envelope*: every pin reads the global epoch (L1 hit ~0.5 ns if cached, but a write by `try_advance`
    invalidates the line → MESI ping-pong ~100+ ns for every reader on the next pin). At N=16 pinners, an unpadded
    epoch counter false-shares with adjacent fields and advance contends on the same line as pins: measured
    **~10× regression** (advance ~30 ns padded vs ~300 ns + reader stalls unpadded). `try_advance` itself is one
    CAS (~25–40 ns) + a quiescence scan over N `Local`s (~N×L1 = ~16×0.5 = 8 ns warm). Bag flush is N `free()` calls
    (~50 ns each, amortized — only every ~1024 retires). Cliff: cold cross-NUMA quiescence scan ~1 µs vs warm ~10 ns
    = **100× cliff** — keep `Local`s NUMA-local (W85 inherits this).
  - **Requirements** R1..R7 — write in `crates/epoch-gc/notes/37_advance_design.md`:
    - R1. `try_advance` is a **CAS loop**, not a single CAS. On CAS success, re-check quiescence before committing
      the reclamation of epoch e−2's bag.
    - R2. Quiescence check: scan all `Local`s; an advance from e→e+1 is legal only if no `Local` is pinned in an
      epoch < e (a Local pinned in e or e+1 is fine; one pinned in e−1 is NOT).
    - R3. A reader that pins between the quiescence check and the CAS pins the NEW epoch (it observed the bump) OR
      the old epoch (it didn't); if it pinned the old (e−1) epoch, advance must NOT reclaim e−2's bag for it — the
      re-check (R1) catches this.
    - R4. `defer` pushes `Garbage` into the **current epoch's** bag of the calling `Local` (single-writer per Local).
    - R5. **Dedup invariant**: a given `Shared` pointer is deferred AT MOST ONCE. Either dedup per-Local before
      flush, OR establish "the unique unlinker is the unique deferrer" and audit callers (the skiplist relies on
      the latter — see Thu delete R4).
    - R6. Global epoch field is `CachePadded<AtomicUsize>` — read on every pin across all threads.
    - R7. Bag flush is amortized: flush per-Local bag into the global queue every ~`Bag::MAX` (~1024) retires;
      `try_advance` drains the global queue for e−2.

  #### Phase 3 — Make the tests pass, one failure at a time (~90 min)
  - **(SENIOR) When `loom_advance_recheck_quiescence` reports a UAF (~iteration 3000):**
    - Symptom: loom flags use-after-free; a thread derefs an `Atomic` whose backing `Box` was freed.
    - Why: `advance()` did a single CAS and reclaimed e−2's bag without re-checking quiescence — a thread pinned
      e−1 between your check and your bump, and you freed memory it still references.
    - Fix: advance is a CAS loop, not a single CAS. On CAS success, re-check quiescence; if a `Local` now pins the
      new epoch that's fine; if a `Local` pins the old (e−1) epoch (it didn't observe your advance), revert the
      reclamation for this round.
    - Cost avoided: a UAF that is silent until a reader stalls long enough to straddle an advance — corrupts the
      memtable read path (bar (c) violation: violates the "no UB on the read hot path" invariant).
    - Muscle: an epoch tick is a transaction over global state — re-validate the precondition after winning the CAS,
      because the world moved. Reapplies at: W42 txn MVCC version-visibility re-check, W74 matching-engine
      cancel-after-fill re-check, W67 raft commit-index advance.
  - **(SENIOR) When `loom_defer_no_double_free` reports a double-free (~iteration 7000):**
    - Symptom: drop counter reads 2 for one pointer; loom flags double-free.
    - Why: `defer_destroy` was called twice on the same `Shared` — a CAS loop wrote the same pointer into the bag on
      a retry that then succeeded.
    - Fix: dedup defers per-`Local` before bag flush; OR establish the invariant "the thread that performs the
      successful unlink is the unique caller of `defer_destroy` for that pointer" and audit every caller (the
      skiplist uses this — only the level-0 unlinker defers).
    - Cost avoided: a double-free that the allocator turns into heap corruption under load — undebuggable in prod
      (bar (c) violation).
    - Muscle: in EBR, "who frees" must be a single, provable owner; never let a retry re-enqueue garbage.
      Reapplies at: W38 memtable freeze (single freeze thread owns the drain), W42 MVCC version reclaim, W74 cancel.
  - **(EXPERT) When `bench_advance_padded_vs_unpadded` shows padded ≈ unpadded (ratio < 5×):**
    - Symptom: padded and unpadded advance cost are within noise — the bench measured nothing real.
    - Why: the global epoch counter shared a cache line with a cold field, so even the "unpadded" variant didn't
      contend; OR the bench ran single-threaded so MESI never fired.
    - Fix: ensure the unpadded variant truly co-locates the epoch with a frequently-written neighbor and the bench
      runs N=16 real threads; wrap the shipped epoch in `CachePadded<AtomicUsize>`.
    - Cost avoided: ~10× advance regression + reader pin-stalls at N=16 (bar (c) violation — MESI ping-pong on the
      hottest counter in the system).
    - Muscle: a perf bench must prove it measures the effect it claims — a negative control (padded vs unpadded with
      an asserted ratio) is non-negotiable for bar (c). Reapplies at: W11 MPMC head/tail false-sharing bench, W58
      matching-engine best-bid/ask bench, W65 Disruptor cursor bench.

  - *Mental model*: a skiplist node is a key/value header followed by a variable-length tower of atomic pointers
    (up to MAX_HEIGHT=12). The tower is walked sequentially on every find — it MUST be contiguous with the header
    to avoid a pointer-chase cache miss per level. The inline-tail pattern is the canonical Rust idiom for this.
  - *Contract*: `Node::new(key, val, height) -> *mut Node` (one allocation); `unsafe fn tower(&self) -> &[Atomic<Node>]`
    returns a slice over the inline tail (`&` access is safe — atomics mutate without `&mut`); empty `Drop`.
  - *Back-of-envelope*: a `Box<[Atomic]>` layout = 2 mallocs/node (~50 ns each = ~100 ns) + a pointer chase per
    tower access (each access = 1 L1 miss if the box isn't in cache = ~100 ns × height). Inline-tail = 1 malloc
    (~50 ns) + the first tower access fetches the line holding header + first ~7 tower entries (1 L1 miss), rest are
    L1 hits (~0.5 ns). On a 10-level walk: **~10 misses (1 µs) vs ~1.5 misses (~80 ns) = ~12× cliff** on the read
    hot path. Tower entry = 1 word (8 B); a 64 B line holds the header tail + ~7 entries.

    - R1. ONE allocation per Node: header + variable tower length stored inline (no `Box<[...]>` indirection).
    - R2. Tower height generated once at allocation time; fixed for the node's lifetime. Geometric p=0.5, MAX_HEIGHT=12.
    - R3. `tower(&self) -> &[Atomic<Node>]` returns a slice over the inline tail; `&` access is safe.
    - R4. Custom `Drop` is empty — frees go through EBR's `defer_destroy`, not Drop.
    - R5. Layout via `Layout::for_value` + `extend`; total size = header_size + height × 8 B. Header struct is
      `#[repr(C)]` so the tower offset is fixed and load-bearing.
    - R6. Node alloc ≤ 50 ns (one malloc per insert); tower access ≤ 5 ns/level warm L1.
