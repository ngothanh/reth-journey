This is a career recon-trip week, not a Build week. There is no crate, no upstream mirror, and no engineered trap-test arc — manufacturing one would be padding. The week's job: turn the accumulated inbound funnel (W122) and the visa/sponsorship homework (W120) into in-person signal before applications open W125, and produce a written, decision-grade firm ranking + cost-of-living model that W124 and W125 consume directly. Every item below names its artifact file and carries an Output line that proves it done; the recon-purpose and cost-of-living items also carry a hardened-acceptance pass criterion and a mental model of why they exist now.

**Monday-Friday — Travel to destination geography**

- [ ] Artifact: `notes/recon_purpose.md` (private). Before travel, write the trip's four objectives so each day's meetings are measured against them, not vibes: (a) meet warm contacts in person, (b) attend a meetup or industry event, (c) get a feel for cost of living / housing / quality of life relative to home, (d) preliminary conversations with target firms (early-stage, NOT formal interviews). For each objective, write the single concrete observation that would mark it "achieved." (~30 min)
  - 🎯 Hardened acceptance: `recon_purpose.md` lists all four objectives (a)-(d), each with a one-line falsifiable success criterion (e.g. "(c) achieved = a rent + monthly-burn number in destination currency I'd actually budget against, with a source"); no objective left as an unmeasurable aspiration.
  - *Mental model*: a recon trip with no written success criteria becomes a vacation with coffee — you return with impressions, not decisions. Writing the four falsifiable criteria up front turns the trip into a data-collection run whose output (the firm ranking + cost model) feeds W124's shortlist and W125's application order directly. This is the only chance to gather in-person signal before applications open; an undefined trip wastes it.
  - Output: `notes/recon_purpose.md` exists with objectives (a)-(d), each carrying a one-line success criterion; `grep -c 'achieved =' notes/recon_purpose.md` ≥ 4.
- [ ] Commit + log (~5 min)
  - Output: `git log -1 --oneline` shows the pre-trip purpose commit.

- [ ] Artifact: `notes/recon_notes.md` (private; no firm names — record each firm as Tier A firm A/B/C/D/E/F so the file is safe if it leaks). Daily target: 2 coffee meetings minimum; one firm office visit if at all possible. Log each meeting with: firm code (A-F), role of person met, one thing learned about the team/stack, one thing learned about hiring posture, and a 1-5 "would I want to work here" gut score. (~30 min/day)
  - 🎯 Hardened acceptance: by Friday `recon_notes.md` records ≥ 8 logged meetings (2/day × 4 weekdays, the Friday-travel day exempt) across ≥ 3 distinct firm codes, each meeting carrying firm-code + role + stack-note + hiring-posture-note + 1-5 score; every firm name is encoded A-F (no real names in the file).
  - *Mental model*: in-person meetings are the only channel that surfaces what a careers page hides — actual stack, team health, hiring urgency, and whether the people are ones you'd want to sit with. Encoding firms as A-F keeps a private file leak-safe while still letting W124/W125 rank by gut-score. Two meetings/day is the floor because the cost of being on-site is already paid; under-booking the calendar wastes the most expensive part of the trip (the flights and the week).
  - Output: `notes/recon_notes.md` contains ≥ 8 dated meeting entries across ≥ 3 firm codes; `grep -c 'score:' notes/recon_notes.md` ≥ 8; no real firm names (`grep -iE '<your-actual-target-firm-names>' notes/recon_notes.md` returns nothing).
- [ ] Artifact: `notes/cost_of_living.md` (private). Capture the (c) objective as numbers, not impressions: monthly rent for the apartment tier you'd actually take, monthly grocery + transport + utilities burn, and the net delta versus your current home cost — all in destination currency with a source (listing URL, receipt, or a local you asked) per line. (~30 min, folded across the week)
  - 🎯 Hardened acceptance: `cost_of_living.md` carries ≥ 5 line items (rent, groceries, transport, utilities, one healthcare/insurance line) each with a number + a source, plus a single computed `net monthly burn` and a `delta vs home` figure; any number you couldn't source is tagged `[UNVERIFIED]` rather than guessed.
  - *Mental model*: a destination role's headline salary is meaningless until netted against local burn — the same $130k is a raise in one geography and a pay cut in another. Producing a sourced burn model now (while you can walk into a supermarket and read price tags) lets W125 evaluate offers on take-home reality, and arms you to counter a lowball with a concrete cost basis rather than a feeling.
  - Output: `notes/cost_of_living.md` exists with ≥ 5 sourced line items + `net monthly burn` + `delta vs home`; every line has a source or an `[UNVERIFIED]` tag.
- [ ] Commit + log nightly (~5 min/day)
  - Output: `git log --oneline` shows one recon-notes commit per travel day.

## Sunday — Recon debrief

- [ ] Artifact: `notes/inbound.md` (update). Fold every new contact and any tentative casual-chat/interview interest from the trip into the existing inbound funnel, with the source meeting (firm code + date) so the lead is traceable back to recon_notes.md. (~30 min)
  - Output: `notes/inbound.md` gains the new trip contacts, each tagged with its firm code + meeting date; `git diff --stat notes/inbound.md` shows added lines.
- [ ] Artifact: `notes/recon_ranking.md` (private). Rank firm codes A-F by combined gut-score + stack-fit + hiring-posture + cost-adjusted comp, and record the timeline decision: if any firm offered a casual chat that could become a next-step on-site → write whether Phase 7 calibrates forward (applications earlier than W125) and why. (~30 min)
  - 🎯 Hardened acceptance: `recon_ranking.md` ranks all met firm codes with a one-line justification each, and ends with an explicit `Phase 7 timeline: hold W125 / pull forward to W___ — <reason>` decision line (a recorded decision, not a vibe), feeding W124's shortlist and W125's application order.
  - *Mental model*: the trip's value evaporates if the impressions aren't converted into a written, ordered decision while they're fresh — a week later the firms blur. Recording the ranking AND the timeline-calibration decision turns recon into the input W125 actually needs (which firms, in what order, starting when), and keeps the Phase 7 schedule honest rather than drifting on enthusiasm.
  - Output: `notes/recon_ranking.md` exists with a ranked firm-code list (one justification each) + an explicit `Phase 7 timeline:` decision line.
- [ ] Commit + log (~5 min)
  - Output: `git log -1 --oneline` shows the Sunday debrief commit.
