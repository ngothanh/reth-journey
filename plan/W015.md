  - 🔧 **Why this matters**: mirrors `crossbeam_epoch::Atomic`'s low-bit tagging. The ABA bug is the single most common lock-free CAS failure: a CAS guards the POINTER bits but not the *value* the pointer named, so a recycled address passes a stale CAS. Three traps: (1) recycle-fast-enough so the same address reappears, (2) believing hazard pointers (drill #19) and tag-ABA-prevention are the same mitigation, (3) sizing the tag. First attempts ship a Treiber stack whose loom test passes only because the allocator never recycles fast enough — it false-greens. Downstream: W22 skiplist-class CAS, W37 skiplist tower CAS, W74 raft term-num wrap, every lock-free stack/queue in the plan.

  - *Mental model*: a Treiber stack is a singly-linked list whose head is one atomic pointer; `pop` is a CAS loop `loop { h = head.load; next = (*h).next; if head.cas(h, next).is_ok() { return h } }`. ABA: between `load` and `cas`, another thread pops `h`, frees it, and a third push reuses the *same address* for a different node with a different `next` — your CAS sees the same bits and succeeds, splicing a stale `next` back as head.
  - *Contract*: `struct Stack<T> { head: AtomicTaggedPtr<Node<T>> }`; `fn push(&self, v: T)`; `fn pop(&self) -> Option<T>`. Tagged variant: the head is an `AtomicU64` packing `(ptr_low_48 | tag_low_16)` OR low-3-bit tagging on a `*mut Node` (Box gives 8-byte alignment ⇒ low 3 bits free). CAS compares the FULL `(ptr, tag)` word.
  - *Back-of-envelope*: pop is one `load` (L1 0.5 ns when hot) + one `compare_exchange` (~10 ns uncontended on x86, dominated by the lock-prefixed RMW). Tag adds a mask + a wider-word compare = ~1-2 ns. The ABA reproduction window = `MAX_ITERATIONS_BEFORE_REUSE / op_rate`: with a per-thread slab recycling slot indices after, say, 1 reuse, the window is *single-digit ops* — that is why ABA is reproducible at all and why a stock allocator hides it (it hands back fresh pages = window of millions).

    - R3. A capture-and-replay harness driving exactly 2 threads through the ABA schedule (pusher-A pushes X; popper-B pops X; pusher-B pushes Y at X's recycled address; popper-A's CAS must succeed on stale bits).

  #### Phase 3 — Make the tests pass, one failure at a time (~75 min)
  Ordered failure cards, newbie first, expert last.
  - **(NEWBIE) When `recycle_actually_reuses_the_address` reports `a0 != a1`:**
    - Symptom: addresses differ; every ABA test below silently passes (false-green).
    - Why: you used `Box::new` per push — the global allocator hands fresh addresses; the recycle window is ~millions of ops, never hit in a test.
    - Fix: back nodes with a fixed slab (`[MaybeUninit<Node<T>>; N]`) and a free-list of slot indices; `push` claims the most-recently-freed slot.
    - Muscle: ABA is only observable when the recycle window is small; a test on a stock allocator proves nothing. Reapplies at: W37 skiplist node recycle, W74 raft log-slot reuse.
  - **(SENIOR) When `aba_fires_untagged_under_recycle` reports `clean` (no corruption):**
    - Symptom: the assertion that corruption is observable fails — the untagged stack behaves correctly.
    - Why: your replay harness let popper-A's `load` and `cas` happen atomically (no preemption point between them), so the interleaving never occurs.
    - Fix: split `pop` into observable steps in the loom model (`let h = head.load(); loom::thread::yield_now(); let r = head.compare_exchange(h, ...)`) so loom can preempt at the gap.
    - Muscle: a CAS loop's vulnerability lives in the gap between `load` and `compare_exchange`; the model must be able to preempt there. Reapplies at: W37 skiplist CAS, W74 raft commit-index CAS.
  - **(SENIOR) When `aba_prevented_tagged` still reports corruption:**
    - Symptom: tagged variant still splices a stale node.
    - Why: you bumped the tag on `pop` not on `push`, or you compared only the pointer half of the word in CAS.
    - Fix: bump the tag on every successful `push` and compare the FULL packed `(ptr, tag)` word in `compare_exchange`.
    - Muscle: the tag must advance on the operation that *reuses* the slot, and the CAS must compare the whole word — pointer-only compare is the ABA hole. Reapplies at: W37 skiplist tower CAS, W74 raft term-num.
  - **(EXPERT) When `tagged_ptr_does_not_derive_clone_into_a_stale_handle` reports ptr bits in the tag region:**
    - Symptom: `p.ptr() & 0b111 != 0` — your tag overlaps real pointer bits.
    - Why: you used low-3-bit tagging on a slab address whose alignment is <8, so the bottom bits are real address.
    - Fix: either guarantee 8-byte alignment (`#[repr(align(8))]` on `Node`) for low-bit tagging, or use the side-channel `AtomicU64` pack `(ptr_low_48 << 16 | tag_low_16)`. Never `#[derive(Clone)]` the handle — make tag advancement explicit.
    - Muscle: low-bit pointer tagging is only valid when alignment guarantees those bits are zero; otherwise version in a side word. Reapplies at: W37 skiplist tagged links, W74 raft entry tags.
  - **Compare** (after green): open `crossbeam_epoch::Atomic` source. They use low bits for `Shared` markers (3 bits on 64-bit). Note: tagging + ABA-prevention is ONE solution; hazard pointers (drill #19) is another; EBR (drill #23) a third. W37 skiplist will silently demand one — you'll discover which fits via the node recycle rate.
