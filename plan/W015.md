- [ ] **Concurrency drill #22 of 28 — ABA via counter wrap (when a 16-bit tag isn't enough)** (solo, ~4 hrs).
  Drill #21 used a tag wide enough to be safe. Now: at what tag width does wraparound recreate ABA? Build
  a measurement that proves a 16-bit tag wraps within minutes under realistic push/pop rates.
  Take drill #21's tagged Treiber stack; replace the 64-bit tag (drill #21's natural size) with a 16-bit
  tag (low 16 bits of pointer — note: this requires 64 KiB alignment, so use a side-channel `AtomicU64`
  encoding (ptr_low_48 | tag_low_16) instead). Run 4 threads doing fast push/pop on a slab-recycled node;
  show after ~65536 ops the tag wraps and you have ABA again.
  Constraints: no peek at how `crossbeam_epoch` sizes its tag bits, no peek at how `folly::AtomicStruct` or
  `lockfree::stack` handle wrap until COMPARE.
  - **Spec**: predict ops/sec on the slab-recycled stack with 4 threads. Compute time to 65536 ops; that's
    your ABA reproduction window. State the exact bit-packing layout you'll use for ptr|tag in a single u64.
  - **Build**: the 16-bit-tag variant. Drive 4 threads for the predicted window. Assert ABA fires
    (capture-and-replay the schedule).
  - **Loom**: not the tool — wraparound is a 65536-op problem, far past loom's exploration budget.
  - **Compare**: open `crossbeam_epoch` source — they use `usize` for tagging via low bits (3 bits on 64-bit
    platforms). Why is 3 bits enough? Because EBR removes the recycle that drives wraparound. Then the
    real-world question: when can you NOT use EBR or hazard pointers and MUST use tags? (Answer: when
    pointer values come from an external recycle source you don't control, e.g. a slab from someone else's
    arena.)
  - **Symptom card**: bug shape (tag wrapped, ABA reborn at high throughput); rule (tag width must be
    log₂(reuse_rate × max_op_window) bits OR pair with hazard pointers / EBR for unbounded safety);
    reapplies at: W37 skiplist tower (uses crossbeam-epoch's 3-bit tag because EBR bounds reuse), W74
    raft term-num wrap (uses u64 term — wraparound is not in scope).
  - **Numbers**: at 4 threads × push/pop on slab-recycled stack, predict ops/sec (~10-50M depending on
    payload). Predict time to 65536 ops (~1-7 ms — very fast). Within 30% or explain.
  - **5-year failure mode**: throughput doubles, ABA window halves. Trigger: 10× scale-up. Fix: u32 tag
    minimum (4 G ops between collisions = ~100 sec at extreme rates); u64 tag for unbounded.
  - **Production handoff**: width calculation `bits ≥ log₂(reuse_rate × ops_per_collision_window)` is the
    rule you'll apply when sizing any tag in production. W37 skiplist + W74 raft term — both rely on this.
