- [ ] **Ép áp lực**: `crates/mini-db/src/per_shard_memory_budget.rs` — enforce ScyllaDB's per-shard memory budget discipline (`max(1.5GB, 7% of total)` default). If a shard exceeds budget, backpressure (reject new work) OR flush memtable to SST. Bench: 16 shards × 1GB on 16GB host, verify no shard exceeds budget under sustained mixed read/write load. (~150 min)
  - 🔧 **Decomposition prompt**: mini-db CAPSTONE scaffold begins this week (W95-W100). The per-shard memtable architecture inherits from runtime-thread-per-core (W85 v1.0); without explicit memory budgeting, a hot shard's memtable grows unbounded → OOM. Scylla's documented default is `max(1.5G, 7% of total)`; today's enforcement makes the budget explicit. Critical because mini-db is the inheritance-ratio capstone (≥0.70 target) — silent shard-OOM defeats the substrate.
  - 🎯 **Hardened acceptance**:
    - **Per-shard budget enforcement**: each `Sharded<Memtable>` instance tracks its memory footprint; on insert, if `current + insert_size > budget`, choose policy: BackpressureRetry (reject + signal upstream) or FlushNow (force-flush memtable to SSTable, free memory, retry).
    - **Bench**: 16-shard mini-db on 16GB host, budget = 1GB/shard, 32GB total workload, sustained mixed (60% read / 40% write) for 5 min; assert no shard's RSS exceeds budget + flush rate is steady-state (no runaway).
    - **Cited URL**: Seastar tutorial (default mem reservation max(1.5G, 7%)); https://github.com/scylladb/seastar/blob/master/doc/tutorial.md.
    - **5-year failure mode**: when CXL.mem pooled memory becomes commodity, per-shard budgets may become cross-shard-borrowable. Migration: budget becomes a soft target with pool-level eviction.
  - **Expect to hit #1 — flush-and-retry creates write amplification cascade**: on budget breach, flush forces a new SSTable; under sustained write burst, this triggers compaction churn that itself consumes memory; system thrashes.
    - Fix: BackpressureRetry as default; FlushNow only when backpressure cannot signal upstream (e.g. WAL replay path). Compaction runs ASYNCHRONOUSLY off-shard.
