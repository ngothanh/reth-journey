# SeqLock blog figures

All code snippets and diagrams are PNGs so they drop straight into beehiiv.

## Layout
- `src/en/*.html`, `src/de/*.html` — diagram + chart sources (per language)
- `src/cards/*.html` — code cards + terminal cards (language-neutral; comments in English)
- `en/*.png`, `de/*.png` — rendered diagrams/charts per language
- `cards/*.png` — rendered code/terminal cards
- `cards.py` + `cards_data.py` — Rust → One Dark code-card generator
- `render.mjs` — HTML → PNG (headless Chrome, 2× DPR, screenshots the `.fig` element)

## Regenerate
```sh
npm install                 # pulls puppeteer (downloads Chromium once)
python3 cards.py            # (re)build code-card HTML from cards_data.py
node render.mjs <src.html> <out.png>   # render one figure
```
Diagrams and the scaling chart are generated by the inline Python in the blog's
build history; the committed `src/*.html` are the reproducible inputs — edit those
and re-run `render.mjs`.

## Style
- Code cards: One Dark (Silicon/Carbon look). Writer gate-comments amber, reader teal.
- Diagrams: dark slate theme; writer=amber, reader=teal, tear/hot=red.
