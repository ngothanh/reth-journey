This is an execution week, not a Build week — the continuation and close-out of the W128 final-round cycle (firms 4, 5, 6, each conditional on the W125 stagger schedule). There is no crate, no upstream mirror, and no engineered trap-test arc — manufacturing one would be padding. The artifact each day produces is a **structured debrief** captured the same evening while memory is fresh; debriefs are the only durable output of an interview and they are the sole input to W131's offer-decision matrix. The new discipline this week, versus W128, is the Saturday cross-firm consolidation: by the end of the week you must be able to rank every firm you finished on evidence, not recency. Day estimates below cover the debrief + targeted recovery prep; the live interview itself is a full external day and is not double-counted in the hour budget. "If scheduled" days (Wed firm 5, Fri firm 6) are conditional — if the W125 stagger left them empty, convert them to recovery + maintenance, do NOT pad.

Each final-round debrief uses the same fixed 4-segment template as W128 so Saturday's cross-firm ranking can pattern-match across all six firms:
```

### Coding
- Prompt: <verbatim>   | Answered: <what you did>   | Stumbled: <exact moment>   | Delta→close-out: <one drill>
### Systems design
- Prompt / budget stated / primitives enumerated / failure interleaving named / where pushed
### Behavioral
- War-story used (which W004/W058 trap or shipped PR) / question / how it landed
### Matching-engine deep-dive
- Which decisions defended (single-writer ring, deterministic replay, back-pressure-as-correctness) vs pushed on
## Fit score: N/10 — <one-line reason>   | ## vs prior firms: <stronger/weaker on team, comp, tech depth, VN-remote friendliness>
```
